# 📚 C# Collections

A collection of C# practice programs demonstrating generic and non-generic collections using simple examples and a WPF application.

## 📂 Projects

### 🟢 1. Generic Collections

Practice examples demonstrating generic collections in C#.

**Collections Covered:**

* `List<T>`
* `Dictionary<TKey, TValue>`
* `HashSet<T>`
* `SortedSet<T>`

**Concepts Covered:**

* Adding and removing elements
* Searching elements using `Contains()`
* Finding maximum and minimum values
* Identifying unique values and duplicates
* Checking even and odd numbers
* Sorting and reversing elements
* Accessing dictionary keys and values

### 🔵 2. Non-Generic Collections

Practice examples demonstrating non-generic collections using the `System.Collections` and related namespaces.

**Collections Covered:**

* `ArrayList`
* `Hashtable`
* `Stack`
* `Queue`
* `SortedList`
* `BitArray`
* `ListDictionary`
* `HybridDictionary`
* `NameValueCollection`
* `StringCollection`
* `StringDictionary`

**Concepts Covered:**

* Adding and removing elements
* Accessing collection elements
* Iterating through collections
* Working with key-value pairs
* Using `Push()`, `Pop()`, and `Peek()` with stacks
* Using `Enqueue()`, `Dequeue()`, and `Peek()` with queues
* Working with string and dictionary collections

## 🛠️ Technologies Used

* 💻 C#
* 🪟 Windows Presentation Foundation (WPF)
* 🎨 XAML
* ⚙️ .NET

## 🎯 Purpose

The purpose of this repository is to understand how generic and non-generic collections work in C#, learn their common operations, and practice managing data using different collection types.

## 📖 Learning Outcome

Through these practice projects, I am learning how to store, access, search, sort, and manage data using different collection classes in C#.

More collection examples will be added as I continue learning.
